# Literature Retrieval-Augmented Generation



This component provides the literature evidence layer of the Autonomous Scientific Data Framework.



## Repository



https://github.com/Sireesiru/RAG-for-Autonomous-Agents



## Role in the Framework



The RAG system retrieves relevant scientific literature to support interpretation of experimental observations and scientific questions generated by the agent.



The retrieval pipeline uses:



\- Scientific text embeddings

\- FAISS vector indexing

\- Maximal Marginal Relevance (MMR) retrieval

\- Source-aware scientific passages

\- LLM-based evidence synthesis



## Integration with the Scientific Agent



The RAG system is exposed to the scientific agent as a literature-search capability through MCP.



The interaction follows:



Scientific observation or question → Scientific Agent → Literature RAG → Relevant scientific evidence → Agent interpretation



The RAG layer provides external scientific evidence but does not calculate experimental measurements or determine DataFed record contents. Experimental values are obtained through the DataFed and scientific-analysis tools.



## Validation



The retrieval system was evaluated using a frozen 50-question benchmark derived from 50 independent literature sources.



The originating paper was recovered within the top three retrieval results for 86% of queries. Semantic evaluation showed that 84% of queries retrieved at least one relevant passage within the top three results and 90% within the top five.



A controlled ablation comparing the same language model with and without literature retrieval showed improved correctness, completeness, and overall answer quality and reduced unsupported claims when RAG evidence was provided.



Detailed evaluation scripts and results are available in the RAG repository.
